# 08 - 计数口径（唯一 Tools.X.y）

> 2026-09-19。定死"族"怎么数，免得同一组数字在两种口径下反复被质疑。

## 口径

**唯一 `Tools.X.y` 串数 / 包 / 族。**

- 数据源：`assets/operit_packages/*.js`。
- 取法：正则 `Tools\.[A-Za-z_]+\.[A-Za-z_]+` 全匹配，`sort -u` 去重后计数。
- **不采用调用次数**（含重复）。调用次数只说明 JS 里写了几次，与需要补多少分支无关。

## 复核命令

```bash
cd assets/operit_packages
# 每包去重
for f in *.js; do printf '%-26s ' "$f"; \
  grep -oE 'Tools\.[A-Za-z_]+\.[A-Za-z_]+' "$f" | sort -u | wc -l; done
# 全命名空间去重
grep -ohE 'Tools\.[A-Za-z_]+\.[A-Za-z_]+' *.js | sort -u | wc -l
```

## 已核数字（2026-09-19 实测）

| 量 | 值 |
|---|---|
| 全命名空间唯一 `Tools.X.y` | 122 |
| 全命名空间调用次数（对照，不作族计数） | 263 |

## 三个量互不相同

1. JS 中出现的方法串去重数 —— **本口径，报"族规模"用它**；
2. `OperitHostDispatcher` 的 `when` 分支数；
3. `KelivoHost` 的方法数。

报"某族缺几个"一律以第 1 个为准；其余两个只在说明实现现状时出现。
